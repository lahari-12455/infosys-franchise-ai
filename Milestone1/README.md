Project Overview

This project implements a user authentication system as part of the Infosys Springboard Internship 7.0, Batch 4, Milestone 1.

Features

- User registration (Signup)
- User login and JWT-based session management
- Forgot Password using a security question
- Forgot Password using email OTP verification
- User dashboard with Logout
- Admin dashboard to view registered users
- Email, password, and required-field validation

Technology Stack

- Python
- Streamlit
- JSON Web Tokens (JWT)
- Google Colab
- ngrok
- Gmail SMTP for sending OTP emails

How to Run

1. Open the project notebook in Google Colab.
2. Configure the required secrets in Colab Secrets.
3. Run the notebook cells in order.
4. Open the public ngrok URL generated by the notebook.
5. Test the Signup, Login, Forgot Password, User Dashboard, and Admin Dashboard features.
