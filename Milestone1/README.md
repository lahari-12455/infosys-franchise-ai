# Infosys Springboard Internship 7.0 - Milestone 1

## 🚀 Project Overview
This project is a secure User Authentication and Management Portal built as part of the Infosys Springboard Internship Milestone 1. It provides robust user management, session handling via JWT, and secure password recovery mechanisms.

## ✨ Features Built
- **User Authentication:** Secure Login and Signup pages.
- **Session Management:** Uses JSON Web Tokens (JWT) to secure user sessions.
- **Password Recovery (Forgot Password):** Supports both Security Questions and Gmail OTP verification.
- **Field & Password Validation:** Ensures strong passwords and proper email formats.
- **Dashboards:** Separate User Dashboard and Admin Dashboard (`infosys@ai`) to view registered users.

## 🛠️ Tech Stack
- **Frontend/UI:** Streamlit
- **Backend/Language:** Python
- **Database:** SQLite
- **Security:** JWT (JSON Web Tokens), Bcrypt (Password Hashing)
- **Networking/Hosting:** ngrok, Google Colab

## 🚀 How to Run
1. Open the provided Google Colab notebook.
2. Configure your Colab Secrets (`JWT_SECRET`, `NGROK_AUTHTOKEN`, `EMAIL_ADDRESS`, `EMAIL_PASSWORD`).
3. Run all cells to launch the Streamlit app and open the public ngrok URL.
